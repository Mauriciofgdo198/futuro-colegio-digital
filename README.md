# futuro colegio digital

Projeto web desenvolvido com React, TypeScript e Vite.

## Desenvolvimento

``bash
npm install
npm run dev
``

## Scripts

-
pm run dev: inicia o ambiente local.
-
pm run build: gera a versão de produção.
-
pm run lint: executa a análise estática.
-
pm run preview: visualiza o build local.
